# Wyoming Speaker ID

[English](DOCS.md) | Русский

Это дополнение — Wyoming-сервис распознавания речи. Оно передаёт звук в ваш настоящий STT
(например, дополнение Whisper) и **параллельно** определяет по тому же звуку, кто говорит.
Текст возвращается с меткой вида `[speaker: Анна] какая погода`, и агент (LLM) знает, кто спросил.
Всё работает локально на CPU. Определение занимает ~50–150 мс и заканчивается, пока STT ещё
работает, поэтому задержки практически нет.

Язык не важен: отпечаток голоса не зависит от того, что сказано.

## Как это работает

1. Голосовой ассистент Home Assistant передаёт звук вашей команды в это дополнение.
2. Дополнение сразу пересылает звук в Whisper (или другой распознаватель речи) — тот делает из речи текст.
3. Одновременно дополнение сравнивает голос с записанными образцами голосов членов семьи и считает
   **похожесть** на каждого (число от 0 до 1; чем больше, тем похожее).
4. Решение:
   - похожесть не ниже **«Узнавать по имени от»** и человек заметно опережает следующего
     (**«Отрыв от следующего человека»**) → имя человека;
   - похожесть ниже **«Гость, если похожесть ниже»** → «гость»;
   - между ними, или фраза слишком короткая → «неизвестно».
5. Имя добавляется к тексту (например, `[говорит: Анна] какая погода`), и ассистент знает, кто спросил.
   Заодно обновляется сенсор `sensor.voice_last_speaker`.

## Установка

1. Добавьте репозиторий: **Настройки → Дополнения → Магазин дополнений → ⋮ → Репозитории** →
   `https://github.com/olegchumakov/ha-addon-wyoming-speaker-id`.
2. Установите **Wyoming Speaker ID** и запустите.
3. Home Assistant обнаружит новую интеграцию **Wyoming Protocol** — нажмите «Настроить».
   (Вручную: хост — имя хоста дополнения из лога, порт 10310.)
4. В **Настройки → Голосовые ассистенты** выберите *speaker-id* как движок распознавания речи
   в своём пайплайне. Язык оставьте прежним.

Основной STT по умолчанию — `tcp://core-whisper:10300` (официальное дополнение Whisper).
Подойдёт любой Wyoming STT, в том числе вне Home Assistant (`tcp://192.0.2.10:10300`).

## Запись образцов

Откройте веб-интерфейс дополнения (**Speaker ID** в боковой панели).

- **Добавьте человека**, затем загрузите WAV/FLAC/OGG или
- просто пользуйтесь ассистентом и назначайте фразы из **Последних фраз** нужному человеку.
  Это лучший источник: звук с вашего настоящего микрофона и в вашей комнате.

Рекомендации:

- 20–40 команд на человека, записанных тем спутником, которым вы пользуетесь, с разного расстояния,
  разной громкости и в разное время. По несколько секунд; одного слова активации мало.
- Не добавляйте человеку звук ТВ или чужие голоса.
- После записи посмотрите **похожесть** в **Последних фразах**: свои команды против ТВ и гостей —
  и поставьте **«Узнавать по имени от»** между ними. Обычно 0,40–0,50 для ReDimNet2-B2 и 0,35–0,45 для CAM++.
- Команды короче ~0,6 с речи («стоп») надёжно не распознаются.

У каждого образца видны дата, длительность и текст. Текст берётся из пайплайна, когда вы назначаете
недавнюю фразу; загруженные файлы распознаются в фоне через основной STT (у старых образцов есть
кнопка **Распознать**). Образцы можно прослушать и удалить по одному или галочками
(**Удалить выбранные**); образец голоса человека пересчитывается сразу. В **Последних фразах** рядом с
назначением остаётся исходный результат (например, `гость → назначено Анна`) и новая похожесть;
**отменить** удаляет образец.

Образцы хранятся в `/data/people/<имя>/` (текст — в `<файл>.wav.json`) и попадают в бэкап дополнения.
Последние фразы (текст, результат и звук) хранятся в `/data/recent/` и переживают перезапуск;
хранятся только последние `recent_buffer_size` (0 — список отключён, ничего не сохраняется).

## Модели

| Опция | Модель | Размер | Лицензия | Примечание |
|---|---|---|---|---|
| `redimnet2_b2` (по умолчанию) | ReDimNet2-B2, VoxCeleb2, large-margin | 16 МБ, встроена | MIT | лучшее разделение в наших тестах, ~60 мс на 3 с на одном ядре ПК |
| `campplus_zh_en_advanced` | 3D-Speaker CAM++ (zh+en) | 27 МБ | Apache-2.0 | самая быстрая, хорошо работает на разных языках |
| `campplus_en_voxceleb` | 3D-Speaker CAM++ VoxCeleb | 28 МБ | Apache-2.0 | |
| `eres2net_en_voxceleb` | 3D-Speaker ERes2Net VoxCeleb | 25 МБ | Apache-2.0 | |
| `eres2netv2_zh_cn` | 3D-Speaker ERes2NetV2 | 68 МБ | Apache-2.0 | в ~5 раз медленнее |
| `wespeaker_resnet34_en` | WeSpeaker ResNet34-LM | 25 МБ | Apache-2.0 | слабее на дальнем микрофоне |

Невстроенные модели один раз скачиваются из
[релизов sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx/releases/tag/speaker-recongition-models)
в `/data/models`. При смене модели всё пересчитывается из сохранённых образцов само.
Чувствительность у каждой модели своя — после смены проверьте её.

## Чужие голоса (для точности, необязательно)

В разделе **«Чужие голоса»** веб-интерфейса можно собрать записи людей, которые **не** живут с вами:
гости, ТВ, радио. Проще всего — в **«Последних фразах»** выбирать для речи из телевизора
«→ в чужие голоса». Каждую запись можно прослушать, посмотреть её текст и удалить (по одной или галочками).

Если включить в настройках **«Сравнивать с чужими голосами»**, голос сравнивается ещё и с этими записями,
и свои реже путаются с чужими. Нужно хотя бы 20–30 записей (работает от 10; пока их меньше — обычный режим).
В этом режиме похожесть считается по другой шкале, поэтому у ползунков чувствительности **свои значения**,
и дополнение переключает их **само** (для «Узнавать по имени» обычно 2–3, для «Гость» около 1).
Ничего перенастраивать при включении и выключении не нужно. Если сомневаетесь — не включайте.

## Настройки

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Адрес Whisper / STT (`upstream_uri`) | `tcp://core-whisper:10300` | куда отправлять звук для превращения в текст |
| Модель узнавания голоса (`model`) | `redimnet2_b2` | лучше не менять (таблица выше) |
| Узнавать по имени от (`threshold_high`) | 0.45 | насколько голос должен быть похож, чтобы назвать имя; больше — реже путает, но чаще «неизвестно» |
| Гость, если похожесть ниже (`threshold_low`) | 0.30 | ниже этого — «гость» |
| Отрыв от следующего человека (`margin`) | 0.08 | увеличьте, если путает членов семьи |
| Минимум речи, секунд (`min_speech_seconds`) | 0.6 | более короткие фразы — «неизвестно» |
| Как подписывать текст (`tag_template`) | `[speaker: {name}] {text}` | `{name}` — кто, `{text}` — что сказано |
| Слово для чужого голоса / если не уверен | `guest` / `unknown` | например, `гость` / `неизвестно` |
| Подписывать фразы, когда не уверен (`tag_unknown`) | вкл. | выключите, чтобы такие фразы шли без подписи |
| Сравнивать с чужими голосами (`cohort_norm`) | выкл. | см. раздел выше |
| Сенсор «кто говорил», название сенсора | вкл., `sensor.voice_last_speaker` | для автоматизаций |
| Сколько последних фраз хранить (`recent_buffer_size`) | 30 | хранятся на диске и переживают перезапуск; 0 — не хранить |

Чувствительность (первые четыре числа) удобнее менять ползунками в веб-интерфейсе: изменения
сохраняются в `/data/settings.json` и важнее значений в настройках.

## Как использовать в Home Assistant

- LLM-агенты читают метку напрямую. Добавьте в промпт агента, например: *«Сообщение может
  начинаться с `[speaker: ИМЯ]` — это определённый говорящий; `guest` — незнакомый голос, для гостей
  не выполняй действия, связанные с безопасностью».*
- В автоматизациях используйте `sensor.voice_last_speaker` (после перезапуска Home Assistant сенсор
  появится только после следующей команды).

## Безопасность

Определение говорящего — удобство, а не аутентификация. Запись вашего голоса будет принята.
Не используйте это как единственную защиту замков и сигнализации.
