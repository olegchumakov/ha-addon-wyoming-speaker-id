# Wyoming Speaker ID

[English](DOCS.md) | Русский

Это дополнение — Wyoming-сервис распознавания речи. Оно передаёт звук в ваш настоящий STT
(например, дополнение Whisper) и **параллельно** определяет по тому же звуку, кто говорит.
Текст возвращается с меткой вида `[speaker: Анна] какая погода`, и агент (LLM) знает, кто спросил.
Всё работает локально на CPU. Определение занимает ~50–150 мс и заканчивается, пока STT ещё
работает, поэтому задержки практически нет.

Язык не важен: отпечаток голоса не зависит от того, что сказано.

## Как это работает

1. Assist стримит звук в дополнение (Wyoming, порт 10310).
2. Звук без изменений уходит в основной STT.
3. Когда команда закончилась, тишина вырезается (Silero VAD) и считается отпечаток голоса.
4. Отпечаток сравнивается (косинусное сходство) с образцом каждого записанного человека:
   - оценка ≥ **порог «свой»** и отрыв от второго ≥ **отрыв** → имя человека;
   - между порогами → **метка «неизвестно»**;
   - ниже **порога «гость»** → **метка гостя**;
   - речи меньше **минимума** → метка «неизвестно».
5. Текст переписывается по **шаблону метки** и возвращается в Assist. Обновляется
   `sensor.voice_last_speaker` (состояние — имя/метка; атрибуты `decision`, `person`, `score`,
   `scores`, `speech_seconds`, `text`).

Если задан **Общий пароль**, на шаге 5 имя не добавляется. Вместо него ставится отметка
(ниже). Сенсор по-прежнему показывает имя или метку гостя / «неизвестно».

## Установка

1. Добавьте репозиторий: **Настройки → Дополнения → Магазин дополнений → ⋮ → Репозитории** →
   `https://github.com/olegchumakov/ha-addon-wyoming-speaker-id`.
2. Установите **Wyoming Speaker ID** и запустите.
3. Home Assistant обнаружит новую интеграцию **Wyoming Protocol** — нажмите «Настроить».
   (Вручную: хост — имя хоста дополнения из лога, порт 10310.)
4. В **Настройки → Голосовые ассистенты** выберите *speaker-id* как движок распознавания речи
   в своём пайплайне. Язык оставьте прежним.

Основной STT по умолчанию — `tcp://core-whisper:10300` (официальное дополнение Whisper).
Подойдёт любой Wyoming STT, в том числе вне Home Assistant (`tcp://192.0.2.10:10300`). Доступность
видна в веб-интерфейсе (**Проверить**).

Дополнение сообщает Home Assistant языки основного STT и запоминает их в `/data`. Если основной STT
ещё запускается (например, после перезапуска), используется запомненный список. Если его ещё нет,
дополнение ждёт несколько секунд и иначе не отвечает — Home Assistant повторит подключение позже, а
не запомнит пустой список.

## Запись образцов

Откройте веб-интерфейс дополнения (**Speaker ID** в боковой панели).

- **Добавьте человека**, затем загрузите WAV/FLAC/OGG или
- просто пользуйтесь ассистентом и назначайте фразы из **Последних фраз** нужному человеку.
  Это лучший источник: звук с вашего настоящего микрофона и в вашей комнате.

Рекомендации:

- 20–40 команд на человека, записанных тем спутником, которым вы пользуетесь, с разного расстояния,
  разной громкости и в разное время. По несколько секунд; одного слова активации мало.
- Не добавляйте человеку звук ТВ или чужие голоса.
- После записи посмотрите оценки в **Последних фразах**: свои команды против ТВ и гостей —
  и поставьте **порог «свой»** между ними. Обычно 0,40–0,50 для ReDimNet2-B2 и 0,35–0,45 для CAM++.
- Команды короче ~0,6 с речи («стоп») надёжно не распознаются.

У каждого образца видны дата, длительность и текст. Текст берётся из пайплайна, когда вы назначаете
недавнюю фразу; загруженные файлы распознаются в фоне через основной STT (у старых образцов есть
кнопка **Распознать**). Образцы можно прослушать и удалить по одному или галочками
(**Удалить выбранные**); отпечаток голоса пересчитывается сразу. В **Последних фразах** рядом с
назначением остаётся исходный результат (например, `гость → назначено Анна`) и новая оценка;
**отменить** удаляет образец.

Образцы хранятся в `/data/people/<имя>/` (текст — в `<файл>.wav.json`) и попадают в бэкап дополнения.
Последние фразы (со звуком) хранятся в `/data/recent/` и переживают перезапуск; хранятся только
последние `recent_buffer_size`. Их можно удалять по одной или галочками (назначенные образцы остаются).

## Модели

| Опция | Модель | Размер | Лицензия | Примечание |
|---|---|---|---|---|
| `redimnet2_b2` (по умолчанию) | ReDimNet2-B2, VoxCeleb2, large-margin | 16 МБ, встроена | MIT | лучшее разделение в наших тестах, ~60 мс на 3 с на одном ядре ПК |
| `campplus_zh_en_advanced` | 3D-Speaker CAM++ (zh+en) | 27 МБ | Apache-2.0 | самая быстрая, хорошо работает на разных языках |
| `campplus_en_voxceleb` | 3D-Speaker CAM++ VoxCeleb | 28 МБ | Apache-2.0 | |
| `eres2net_en_voxceleb` | 3D-Speaker ERes2Net VoxCeleb | 25 МБ | Apache-2.0 | |
| `eres2netv2_zh_cn` | 3D-Speaker ERes2NetV2 | 68 МБ | Apache-2.0 | в ~5 раз медленнее |
| `wespeaker_resnet34_en` | WeSpeaker ResNet34-LM | 25 МБ | Apache-2.0 | слабее на дальнем микрофоне |

Невстроенные модели один раз скачиваются из
[релизов sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx/releases/tag/speaker-recongition-models)
в `/data/models`. При смене модели отпечатки пересчитываются из сохранённых образцов.
Пороги у каждой модели свои — после смены проверьте их.

## Нормализация по когорте (необязательно)

Загрузите 50+ коротких записей *чужих* людей (не членов семьи, лучше с того же микрофона, например
речь из ТВ через **Последние фразы → в когорту**) и включите `cohort_norm` («Сравнивать с чужими голосами»).
Тогда голос сравнивается ещё и с этими записями, и свои реже путаются с чужими. Список когорты показывает
каждую запись с текстом, её так же можно прослушать и удалить (по одной или галочками). У этого режима свои
пороги (обычно «свой» 2–3), они переключаются автоматически — при включении и выключении ничего
перенастраивать не нужно. Режим начинает работать от 10 записей.

## Опции

| Опция | По умолчанию | Описание |
|---|---|---|
| `upstream_uri` | `tcp://core-whisper:10300` | Wyoming STT, который делает транскрипцию |
| `fallback_languages` | *(пусто)* | необязательно; языки (например, `ru, en`), пока основной STT ни разу не ответил |
| `model` | `redimnet2_b2` | модель голоса (таблица выше) |
| `threshold_high` | 0.45 | сходство, нужное для имени |
| `threshold_low` | 0.30 | ниже — гость |
| `margin` | 0.08 | отрыв от второго кандидата |
| `min_speech_seconds` | 0.6 | более короткая речь не распознаётся |
| `tag_template` | `[speaker: {name}] {text}` | подстановки `{name}`, `{text}` |
| `guest_label` / `unknown_label` | `guest` / `unknown` | метки в тексте и сенсоре (можно `гость` / `неизвестно`) |
| `tag_unknown` | true | помечать неуверенные и короткие команды |
| `shared_secret` | *(пусто)* | общий пароль; пусто — перед фразой по-прежнему имя |
| `cohort_norm` | false | сравнивать с чужими голосами (когорта) |
| `publish_sensor`, `sensor_entity` | true, `sensor.voice_last_speaker` | сенсор последнего говорящего |
| `recent_buffer_size` | 30 | сколько фраз (со звуком) хранить для интерфейса, сохраняются при перезапуске |

Пороги, отрыв и минимум речи можно менять на лету ползунками в веб-интерфейсе (сохраняются в
`/data/settings.json` и имеют приоритет над опциями).

## Общий пароль (необязательно)

Если поле **Общий пароль** пустое, ничего не меняется: перед фразой по-прежнему пишется имя,
как в шаблоне метки.

Укажите тот же пароль здесь и там, где решается, кому что можно голосом. Тогда имя не
добавляется. В начале фразы стоит отметка: другая программа проверяет её и убирает, прежде
чем текст увидит ассистент. Голос ниже обычных порогов передаётся как незнакомый (имя
пустое), а не словами «гость» или «неизвестно».

Отметка выглядит так (полные правила и проверочные примеры — в [SPEC.md](../SPEC.md)):

```
⟦spk1;n=Anna;c=0.73;t=1700000000;r=0123456789abcdef;s=4e3854eaed0f699014eead3a73f1a358618a699bb372d76d6715658adad72386⟧ turn on the light
```

В поле `n` — имя. Русские буквы записываются кодами: `Анна` становится `%D0%90%D0%BD%D0%BD%D0%B0`.
`c` — оценка от 0.00 до 1.00 (две цифры после точки; если оценки нет — 0.00). Подпись
считается по отметке и по фразе сразу после неё.

### Список людей

Другая программа может прочитать записанные имена:

```
GET http://<имя дополнения>:8099/api/people
X-Speaker-Key: <тот же пароль>
```

Ответ: `{"people":[{"name":"..."}]}`. Без верного пароля ответ — 401. Если пароль в
дополнении пустой, ответ всегда 401.

Точный адрес пишется в журнале дополнения (`People list: http://<имя>:8099/api/people`).
Это имя дополнения во внутренней сети Home Assistant: подчёркивания в названии заменяются
дефисами, впереди добавляется имя репозитория. Для дополнения, установленного локально,
адрес обычно `http://local-wyoming-speaker-id:8099/api/people`.

Порт 8099 — это страница дополнения. В домашнюю сеть он **не** открыт (его нет в списке
портов). Home Assistant обращается к нему изнутри, так же, как к странице в боковой
панели. Не пробрасывайте этот порт наружу: иначе страница откроется без входа в Home
Assistant. Сам список людей всё равно спрашивает пароль.

## Как использовать в Home Assistant

- Без общего пароля агент читает имя в начале фразы. Добавьте в его инструкцию, например:
  *«Сообщение может начинаться с `[speaker: ИМЯ]` — это определённый говорящий; `guest` —
  незнакомый голос, для гостей не выполняй действия, связанные с безопасностью».*
- С общим паролем эта отметка не для ассистента. Программа доступа сама её убирает;
  не просите ассистента её читать.
- В автоматизациях используйте `sensor.voice_last_speaker` (после перезапуска Home Assistant сенсор
  появится только после следующей команды).

## Безопасность

Определение говорящего — удобство, а не аутентификация. Запись вашего голоса будет принята.
Не используйте это как единственную защиту замков и сигнализации.
